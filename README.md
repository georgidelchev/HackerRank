## 📖 About

This repository contains my personal solutions to problems on **[HackerRank](https://www.hackerrank.com)** — one of the world's leading competitive programming and technical assessment platforms used by developers and companies alike.

The repo spans multiple challenge tracks and certification paths, covering general algorithm problems across difficulty tiers, the 30 Days of Code challenge, and HackerRank's official C# skill certification problems. All solutions are written in **C#** and optimised for correctness and readability.

## 💡 What is HackerRank?

[HackerRank](https://www.hackerrank.com) is a global competitive programming platform used by over 23 million developers and 3,000+ companies worldwide. It features challenges across algorithms, data structures, mathematics, databases, and more — and offers official skill certifications that are widely recognised in technical hiring.

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/georgidelchev/HackerRank.git
   cd HackerRank
   ```

2. **Pick a section** and open any `.cs` file in Visual Studio, Rider, or VS Code.

3. **Find the original problem** at [hackerrank.com](https://www.hackerrank.com) to read the full problem statement and compare your own approach.
